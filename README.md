# 🤖 Полина — Telegram-юзербот

Юзербот на [Telethon](https://docs.telethon.dev) для личного аккаунта Telegram:
голосовые командой `.гс`, таймеры «Полина, таймер через 4 часа ферма», тег всех,
погода. Работает 24/7 на хостинге [Bothost](https://bothost.ru).

---

## Возможности

| Команда | Кто может | Что делает |
|---|---|---|
| `.гс текст` | только вы | Голосовое женским голосом (озвучивает текст). Ответьте `.гс` на чужое сообщение — озвучит его |
| `.все @группа [текст]` | только вы, **из ЛС Полине** | Тихий призыв: тегает участников по 5 и сразу удаляет сообщения в группе, прогресс шлёт вам в ЛС. Полина должна состоять в группе. ⚠️ Аккуратно! |
| `.стоп` | только вы, из ЛС | Прервать идущий тег |
| `.отложка @чат 4 часа 1 минута ферма` | только вы, из ЛС | ⏳ Заполняет отложенные сообщения Telegram (до 100) + авто-пополнение |
| `.погода город` | только вы | Текущая погода (Open-Meteo, без ключей) |
| `.пинг` | только вы | Жив ли бот, аптайм, число таймеров |
| `.ид` | только вы | ID чата; ответом на сообщение — ещё и ID человека |
| `.полина вкл/выкл` | только вы | Разрешить/запретить публичные команды в конкретном чате |
| `.привет вкл/выкл/сразу/триггер/текст` | только вы | Приветствие новичков в группе (плейсхолдеры `{name}`, `{chat}`) |
| `.вестник вкл/выкл/время/сейчас` | только вы | 🗞 Лог переписки за день файлом .md вам в ЛС (для своего дайджеста) |
| `.квиз [часов]` | только вы | 🏆 Итоги викторин: таблица лидеров, кто чаще отвечал правильно |
| `.помощь` | только вы | Список команд (сообщение само удалится через минуту) |
| «Полина, таймер через 4 часа ферма» | **все в чате** | Через 4 часа Полина ответит на сообщение и тегнет автора |
| «Полина, каждые 4 часа ферма» | все в чате | 🔁 Повторяющееся напоминание до отмены (минимум раз в 5 минут) |
| «Полина, таймер в 18:30 созвон» | все в чате | Напоминание на конкретное время |
| «Полина, таймеры» | все в чате | Список активных таймеров чата |
| «Полина, отмена 5» | автор / вы | Отменить таймер №5 |
| «Полина, погода Москва» | все в чате | Погода |
| «Полина, запомни X: Y» / «заметки» / «забудь N» | все в чате | Заметки чата (до 50) |
| «Полина, кто самый умный?» | все в чате | 🎯 Выбирает случайного участника и тегает |
| «Полина, выбери: пицца или суши» | все в чате | Случайный выбор (варианты через «или» или запятую) |
| «Полина, кубик» | все в чате | Бросает анимированный кубик Telegram 🎲 |
| «Полина, шар: идти на ферму?» | все в чате | 🔮 Магический шар: да / нет / спроси позже |
| «Полина, помощь» | все в чате | Короткая справка |

Парсер времени понимает: «через 30 минут», «через 1 час 30 минут», «через полчаса»,
«через час», «через 1.5 часа», «через 2 дня», «через неделю», «в 18:30».
Слово «таймер» можно заменить на «напомни». Повторы: «каждые 4 часа», «каждый час»,
«каждые 30 минут» (работает и в форме «таймер каждые 4 часа ферма»).

Таймеры хранятся в SQLite и **переживают перезапуск бота** (разовый просроченный
сработает сразу с пометкой; повторяющийся догонит своё расписание, а если опоздал
совсем чуть-чуть — напомнит разок с пометкой о задержке).

## 👥 Тихий тег `.все` (из ЛС)

Команду даёте **со своего основного аккаунта в личке с Полиной** — не в самой группе:

```
.все @bermuda_chat
.все -1001234567890 Сбор на ферму!
```

- Полина тегает участников целевой группы **пачками по 5** и каждое сообщение
  через ~1 сек **удаляет** — в группе не остаётся кучи тегов.
- **Текст** (`.все @чат Утро доброе, сладость 🥳`) добавляется в **каждую** пачку:
  сообщения тоже удаляются, но у людей в пуш-уведомлении виден и текст, и тег.
  Чат остаётся чистым.
- Прогресс идёт вам в ЛС одним сообщением: `Прогресс: 15/47` → `✅ Готово`.
- Команда работает только от аккаунта `OWNER_ID` и только в личке.
- Полина должна **состоять в группе**; для больших групп — лучше администратором,
  иначе Telegram не отдаёт полный список участников.
- Узнать ID группы: перешлите любое её сообщение боту `@userinfobot`, либо
  используйте `@username` (у публичных групп).

`.все` без аргументов пришлёт подсказку по формату. Прервать идущий тег — `.стоп` (в ЛС).

## ⏳ Отложенные сообщения (`.отложка`)

Telegram умеет сам доставлять **отложенные сообщения** (лимит **100 на чат**,
горизонт до года). Полина заполняет эту очередь — и сообщения выходят по
расписанию, **даже если бот или хостинг лежат**.

Команды — в ЛС Полине с вашего основного аккаунта:

```
.отложка @чат 4 часа 1 минута ферма   — заполнить очередь (первое через ~1 мин)
.отложка @чат                          — статус: сколько в очереди, первое/последнее
.отложка стоп @чат                     — выключить авто-пополнение
.отложка очистить @чат                 — удалить все отложенные и выключить авто
```

- 100 сообщений с шагом 4 ч 01 мин ≈ **16,7 суток** покрытия.
- 🔁 **Авто-пополнение**: раз в 6 часов Полина дозаполняет очередь до 100,
  продолжая цепочку без сбоя ритма — «ферма» не закончится никогда.
  Настройка хранится в базе и переживает перезапуск.
- Участники очередь не видят — сообщения просто появляются по расписанию.
- Ограничения: интервал от 5 минут до 7 дней; целевой чат должен быть
  в `ALLOWED_CHATS`.

## 🗞 Вечерний вестник — лог чата файлом в ЛС

Полина тихо запоминает переписку чата, а вечером (или по команде) присылает
**вам в личку файл `.md` со всеми сообщениями за 24 часа** — готовый материал
для дайджеста через любой внешний сервис.

### Что в файле

- Шапка: дата, число сообщений и участников
- **Топ активности** (кто сколько написал, с id)
- Все сообщения: `[ЧЧ:ММ] Имя (id:123): текст` — id пригодятся, чтобы ваш
  сервис сделал кликабельные теги (`[Имя](tg://user?id=123)`)
- Медиа-события: `[фото]`, `[стикер]`, `[голосовое]`, `[кружок]`, `[гифка]`

### Команды (в группе или в ЛС Полине)

```
.вестник               — статус: вкл/выкл, время, сколько сообщений в архиве
.вестник вкл / выкл     — ежедневная отправка файла в ЛС
.вестник время 21:00    — во сколько присылать (часовой пояс TIMEZONE)
.вестник сейчас         — прислать файл прямо сейчас
```

### Как устроено

- В лог попадают только сообщения людей из разрешённого чата; команды с точкой,
  боты и сообщения самой Полины — нет. Хранится 3 суток, потом чистится.
- Лимитов на объём нет — в файл выгружается **вся** переписка за сутки.
- Если за день сообщений не было — Полина напишет об этом в ЛС вместо файла.

## 🏆 Итоги викторин (`.квиз`)

Владелец чата постит квизы (опросы-викторины), а Полина сама считает результаты:

```
.квиз                        — итоги за последние 24 часа
.квиз 12                     — за последние 12 часов (1–72)
.квиз https://t.me/c/…/123   — от указанного сообщения (ссылка на ПЕРВЫЙ квиз)
```

💡 **Самый надёжный способ** — ссылка на первый квиз (в Telegram: долгое нажатие
на сообщение → «Копировать ссылку»). Полина начнёт ровно с него и найдёт все
следующие — не важно, сколько сообщений было после. Режим по часам сканирует
последние 3000 сообщений — в очень активном чате старые квизы могут не попасть.

Где запускать:
- **в группе** — результат публикуется в группе (все видят таблицу);
- **в ЛС Полине** — результат придёт тихо в личку: можно сначала посмотреть
  самому, а потом уже кинуть в чат.

Полина сканирует историю, находит квизы, смотрит кто как проголосовал и публикует
таблицу лидеров: 🥇🥈🥉 топ-3 с тегами, остальные — текстом, у каждого счёт
правильных ответов (например «9/10»).

**Важные условия:**
- Квизы должны быть **неанонимными** (видно, кто голосовал) — анонимные Полина
  пропустит и честно об этом скажет.
- Правильный ответ виден Полине, только если **она сама проголосовала** в квизе —
  поэтому отвечайте на все вопросы с аккаунта Полины (её голос в зачёт не идёт).
- Работает и с пересланными квизами (например, из канала с викторинами).

## 📝 Заметки

Любой участник (и вы) может сохранять заметки — работает в группе и в личке с Полиной:

- «Полина, запомни пароль: 1234» — именованная (перезаписывается по ключу)
- «Полина, запомни купить корм коту» — обычная заметка с номером
- «Полина, заметки» — список
- «Полина, заметка пароль» / «Полина, заметка 3» — показать
- «Полина, забудь 3» — удалить (автор или владелец)

До 50 заметок на чат.

## 👋 Приветствие новичков

Полина может здороваться с новыми участниками. Настраивается командой `.привет`
**в самой группе** (под аккаунтом Полины или с вашего основного аккаунта):

- `.привет` — статус, режим и текущий текст
- `.привет вкл` / `.привет выкл`
- `.привет текст Добро пожаловать, {name}! Ты в «{chat}» 🌴`

Плейсхолдеры: `{name}` — упоминание новичка, `{chat}` — название группы.

### Два режима

- **`.привет сразу`** (по умолчанию) — здоровается, как только человек вступил.
- **`.привет триггер`** — для чатов с ботом-охранником (напр. **SecurityBermuda**),
  который удаляет системное сообщение о входе и сам пишет «Добро пожаловать».
  Полина реагирует на сообщение охранника и определяет новичка так:
  1. берёт его **прямо из упоминания** в сообщении охранника — кликабельное имя,
     ссылка `tg://user` или `@username` (работает всегда, даже если вход не был
     пойман Полиной);
  2. если упоминания нет — берёт из очереди недавних входов.

  Отвечает приветствием прямо на сообщение охранника.
  - `.привет триггер` — фраза «добро пожаловать» от любого бота
  - `.привет триггер @SecurityBermuda` — «добро пожаловать» только от этого бота
  - `.привет триггер <своя фраза>` — своя фраза-триггер (от любого бота)

> Диагностика в логах Bothost: `вход: N чел. в чате …` — вход пойман;
> `приветствую <имя> … — по упоминанию/из очереди` — кого и как поприветствовала.
> Если охранник вообще не упоминает новичка и вход не ловится (заявки на
> вступление) — напишите, сделаем под этот случай.

## 🚀 Деплой на Bothost — 5 шагов

Официальная инструкция Bothost для юзерботов: <https://bothost.ru/docs/telegram-userbot-setup>

### Шаг 1. api_id и api_hash

[my.telegram.org](https://my.telegram.org) → API development tools → создайте
приложение → скопируйте **api_id** и **api_hash**.
Если вы уже запускали Telethon-скрипты — эти значения у вас есть.

### Шаг 2. SESSION_STRING

На Bothost нет интерактивного терминала (нельзя ввести код из Telegram),
поэтому нужна **строка сессии**. Получите её локально на своём компьютере:

**Вариант А — из существующего `.session`-файла** (повторный вход не нужен):

```bash
pip install telethon
python convert_session.py
```

**Вариант Б — новая сессия** (вход по номеру и коду):

```bash
python gen_session.py
```

> ⚠️ Строка сессии = полный доступ к аккаунту. Никому не отправляйте её,
> не коммитьте в Git. Вставляется ТОЛЬКО в переменные окружения на Bothost.

### Шаг 3. Код — в Git

Залейте эту папку в свой репозиторий GitHub/GitLab. Секретов в коде нет,
но лучше сделать репозиторий приватным (Bothost умеет подключать ваш
GitHub-аккаунт для приватных репозиториев).

### Шаг 4. Создание бота на Bothost

На [bothost.ru](https://bothost.ru) → «Создать бота»:

- **Платформа:** Telegram
- **Библиотека:** Telethon
- **Git URL:** ссылка на ваш репозиторий, ветка `main`
- **Дополнительные настройки → Главный файл:** `userbot.py`
- **Переменные окружения:**

| Переменная | Значение |
|---|---|
| `TELEGRAM_API_ID` | ваш api_id (число) |
| `TELEGRAM_API_HASH` | ваш api_hash |
| `SESSION_STRING` | строка из шага 2 |
| `OWNER_ID` | ID вашего основного аккаунта — для тега `.все` из ЛС (напр. `8492109371`) |
| `ALLOWED_CHATS` | ID чата(ов), где Полина работает (напр. `-1001849529736`); пусто = везде |

Bot Token от @BotFather юзерботу **не нужен** — следуйте инструкции Bothost
для юзерботов (ссылка выше), а не обычному мастеру ботов.

### Шаг 5. Деплой и проверка

Запустите развёртывание и откройте логи. Должно появиться:

```
✅ Полина запущена на аккаунте: <ваше имя> (id …)
```

Отправьте в любой чат `.пинг`, затем `.помощь`. Готово — бот работает 24/7,
обновления подтягиваются автоматически при `git push`.

## Частые проблемы

- **`EOF when reading a line`** — не заданы переменные окружения, и код просит
  ввод. Проверьте `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `SESSION_STRING`.
- **`SESSION_STRING недействительна`** — сессия отозвана (Настройки Telegram →
  Устройства) или сгенерирована с другими api_id/api_hash. Сгенерируйте новую.
- **`ffmpeg не найден`** — на Bothost пересоберите бота: ffmpeg ставится
  автоматически, потому что в `requirements.txt` есть `ffmpeg-python`.
  Локально установите ffmpeg вручную.
- **Голосовое не отправляется** — смотрите логи: обычно это сеть до сервиса
  озвучки; бот напишет причину вместо голосового.
- **Бот молчит на «Полина, …»** — проверьте, не выключены ли публичные команды
  в этом чате (`.полина вкл`), и имя в `BOT_NAME`.
- **Таймеры пропали после передеплоя** — база лежит в `DATA_DIR` (по умолчанию
  `/app/data`, эта папка на Bothost сохраняется между деплоями).

## ⚠️ Важно про юзерботы

- Юзерботы официально **не поддерживаются Telegram**. Спам и массовые теги
  могут привести к ограничению аккаунта — используйте `.все` умеренно
  (в боте уже стоят паузы и лимиты).
- **Не запускайте параллельно** другие скрипты с этой же сессией — будут
  конфликты. Для бота лучше отдельная сессия (`gen_session.py`).
- Все секреты — только в переменных окружения, никогда в коде и чатах.

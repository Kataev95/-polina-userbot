# 🤖 Полина — Telegram-юзербот

Юзербот на [Telethon](https://docs.telethon.dev) для личного аккаунта Telegram:
голосовые командой `.гс`, таймеры «Полина, таймер через 4 часа ферма», тег всех,
погода. Работает 24/7 на хостинге [Bothost](https://bothost.ru).

---

## Возможности

| Команда | Кто может | Что делает |
|---|---|---|
| `.гс текст` | только вы | Голосовое женским голосом (озвучивает текст). Ответьте `.гс` на чужое сообщение — озвучит его |
| `.все [текст]` | только вы | Упоминает участников группы пачками по 5 (максимум 100). ⚠️ Аккуратно! |
| `.погода город` | только вы | Текущая погода (Open-Meteo, без ключей) |
| `.пинг` | только вы | Жив ли бот, аптайм, число таймеров |
| `.ид` | только вы | ID чата; ответом на сообщение — ещё и ID человека |
| `.полина вкл/выкл` | только вы | Разрешить/запретить публичные команды в конкретном чате |
| `.помощь` | только вы | Список команд (сообщение само удалится через минуту) |
| «Полина, таймер через 4 часа ферма» | **все в чате** | Через 4 часа Полина ответит на сообщение и тегнет автора |
| «Полина, таймер в 18:30 созвон» | все в чате | Напоминание на конкретное время |
| «Полина, таймеры» | все в чате | Список активных таймеров чата |
| «Полина, отмена 5» | автор / вы | Отменить таймер №5 |
| «Полина, погода Москва» | все в чате | Погода |
| «Полина, помощь» | все в чате | Короткая справка |

Парсер времени понимает: «через 30 минут», «через 1 час 30 минут», «через полчаса»,
«через час», «через 1.5 часа», «через 2 дня», «через неделю», «в 18:30».
Слово «таймер» можно заменить на «напомни».

Таймеры хранятся в SQLite и **переживают перезапуск бота** (если таймер просрочен
за время рестарта — сработает сразу с пометкой).

## 🚀 Деплой на Bothost — 5 шагов

Официальная инструкция Bothost для юзерботов: <https://bothost.ru/docs/telegram-userbot-setup>

### Шаг 1. api_id и api_hash

[my.telegram.org](https://my.telegram.org) → API development tools → создайте
приложение → скопируйте **api_id** и **api_hash**.
Если вы уже запускали Telethon-скрипты — эти значения у вас есть.

### Шаг 2. SESSION_STRING

На Bothost нет интерактивного терминала (нельзя ввести код из Telegram),
поэтому нужна **строка сессии**. Получите её локально на своём компьютере:

**Вариант А — из существующего `.session`-файла** (повторный вход не нужен):

```bash
pip install telethon
python convert_session.py
```

**Вариант Б — новая сессия** (вход по номеру и коду):

```bash
python gen_session.py
```

> ⚠️ Строка сессии = полный доступ к аккаунту. Никому не отправляйте её,
> не коммитьте в Git. Вставляется ТОЛЬКО в переменные окружения на Bothost.

### Шаг 3. Код — в Git

Залейте эту папку в свой репозиторий GitHub/GitLab. Секретов в коде нет,
но лучше сделать репозиторий приватным (Bothost умеет подключать ваш
GitHub-аккаунт для приватных репозиториев).

### Шаг 4. Создание бота на Bothost

На [bothost.ru](https://bothost.ru) → «Создать бота»:

- **Платформа:** Telegram
- **Библиотека:** Telethon
- **Git URL:** ссылка на ваш репозиторий, ветка `main`
- **Дополнительные настройки → Главный файл:** `userbot.py`
- **Переменные окружения:**

| Переменная | Значение |
|---|---|
| `TELEGRAM_API_ID` | ваш api_id (число) |
| `TELEGRAM_API_HASH` | ваш api_hash |
| `SESSION_STRING` | строка из шага 2 |

Bot Token от @BotFather юзерботу **не нужен** — следуйте инструкции Bothost
для юзерботов (ссылка выше), а не обычному мастеру ботов.

### Шаг 5. Деплой и проверка

Запустите развёртывание и откройте логи. Должно появиться:

```
✅ Полина запущена на аккаунте: <ваше имя> (id …)
```

Отправьте в любой чат `.пинг`, затем `.помощь`. Готово — бот работает 24/7,
обновления подтягиваются автоматически при `git push`.

## Все переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|---|---|---|---|
| `TELEGRAM_API_ID` | ✅ | — | API ID с my.telegram.org |
| `TELEGRAM_API_HASH` | ✅ | — | API Hash с my.telegram.org |
| `SESSION_STRING` | ✅ | — | Строка сессии Telethon |
| `BOT_NAME` | — | `Полина` | Имя, на которое бот откликается |
| `TTS_VOICE` | — | `ru-RU-SvetlanaNeural` | Голос (.гс). Мужской: `ru-RU-DmitryNeural` |
| `TTS_RATE` | — | `+0%` | Скорость речи: `+15%`, `-10%` … |
| `TTS_MAX_LEN` | — | `800` | Максимум символов на озвучку |
| `TIMEZONE` | — | `Europe/Moscow` | Часовой пояс для «в 18:30» |
| `TAGALL_LIMIT` | — | `100` | Максимум людей для `.все` |
| `DATA_DIR` | — | `/app/data` | Папка базы данных таймеров |

## Частые проблемы

- **`EOF when reading a line`** — не заданы переменные окружения, и код просит
  ввод. Проверьте `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `SESSION_STRING`.
- **`SESSION_STRING недействительна`** — сессия отозвана (Настройки Telegram →
  Устройства) или сгенерирована с другими api_id/api_hash. Сгенерируйте новую.
- **`ffmpeg не найден`** — на Bothost пересоберите бота: ffmpeg ставится
  автоматически, потому что в `requirements.txt` есть `ffmpeg-python`.
  Локально установите ffmpeg вручную.
- **Голосовое не отправляется** — смотрите логи: обычно это сеть до сервиса
  озвучки; бот напишет причину вместо голосового.
- **Бот молчит на «Полина, …»** — проверьте, не выключены ли публичные команды
  в этом чате (`.полина вкл`), и имя в `BOT_NAME`.
- **Таймеры пропали после передеплоя** — база лежит в `DATA_DIR` (по умолчанию
  `/app/data`, эта папка на Bothost сохраняется между деплоями).

## ⚠️ Важно про юзерботы

- Юзерботы официально **не поддерживаются Telegram**. Спам и массовые теги
  могут привести к ограничению аккаунта — используйте `.все` умеренно
  (в боте уже стоят паузы и лимиты).
- **Не запускайте параллельно** другие скрипты с этой же сессией — будут
  конфликты. Для бота лучше отдельная сессия (`gen_session.py`).
- Все секреты — только в переменных окружения, никогда в коде и чатах.
